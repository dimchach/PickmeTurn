# PickmeTurn 1.2.7

## Изменения
- Обновлено ядро FreeTurn с версии 4.1.0 до 4.2.0.
- Обновлены сценарии сборки и документация для использования FreeTurn 4.2.0.
- Обновлена версия приложения и установщика до 1.2.7.
- В информации о программе теперь отображается актуальная версия FreeTurn Core — 4.2.0.
- Advanced CAPTCHA теперь включён по умолчанию для новых пользователей.
- Состояние Advanced CAPTCHA сохраняется между запусками приложения.

## Примечание
Advanced CAPTCHA остаётся экспериментальной функцией. Её можно включать и отключать в настройках приложения.
