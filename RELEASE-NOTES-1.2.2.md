# PickmeTurn 1.2.2

Release version with stability, performance, and relay-stream improvements.

## Изменения

- Добавлен индикатор `Потоки: X/12`.
- FreeTurn запускается с явным лимитом `-n 12`.
- Счётчик отображает активные TURN allocations и обновляется только при изменении их состояния.
- Убран лишний вызов UI Dispatcher на каждую строку лога FreeTurn.
- Исправлен выбор локального relay-порта: свободный порт выбирается до формирования WireGuard-конфига.
- `NormalizeWireGuard()` теперь использует фактически выбранный порт, а не устаревшее значение.
- Исправлено диагностическое сообщение о локальном relay-порте.

## Инспекция

Фоновый монитор FreeTurn остаётся единственным периодическим монитором активной сессии и работает с интервалом 2 секунды. Буфер лога ограничен 12000 символами. В штатном режиме дополнительные UI-обновления по каждой строке FreeTurn не выполняются.
